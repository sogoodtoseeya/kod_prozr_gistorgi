# «Прозрачные торги» — синтетический корпус данных и движок правил

Детерминированный набор данных (seed=42) для системы автоматизированного
контроля конфликта интересов в торгах по реализации государственного и
муниципального имущества (аукционы на аренду земельных участков, ст. 39.11-39.13 ЗК РФ).

## Состав данных (data/)
| Файл | Содержимое |
|---|---|
| employees.csv | 25 муниципальных служащих (19 действующих, 6 уволенных) |
| persons.csv | 75 физических лиц и ИП, разбитых по категориям |
| organizations.csv | 30 организаций (7 рисковых, 17 чистых участников, 6 не участвуют) |
| auctions.csv | 60 аукционов, участок -> аукцион |
| applications.csv | 188 заявок (30 золотых + 158 чистых, часть отклонена по формальным основаниям) |
| kinship.csv | 44 родственные связи (13 золотых, 31 шумовых) |
| contracts.csv | 26 договоров на кадастровые работы (7 золотых, 19 шумовых на невыставленных участках) |
| founders.csv | 47 учредителей |
| graph_edges.csv | 390 рёбер единого графа — единственный вход движка |
| golden_cases.csv | эталон: 30 золотых случаев КИ |

## Состав золотого набора (30 случаев)
- R1 (7): договор участника на кадастровые работы по выставленному участку;
- R2 (8): родственник действующего служащего среди заявителей
  (супруга x2, ребёнок x2, родитель x1, брат x1, племянник x1 — «серый» GC-29, сестра x1);
- R3 (4): учредитель организации-участника — родственник служащего (приоритет средний);
- R4 (6): бывший сотрудник среди заявителей (3) и учредителей (3);
- R5 (5): заявку подал действующий служащий.

Флагманский случай GC-01: кадастровый инженер P-007 с договором CT-999
на межевание участка ZU-77:15:0101-1 подал заявку на аукцион AU-001 по этому
же участку; дополнительно он двоюродный брат служащего EMP-018. Эталон: правила R1+R2, приоритет высокий.

## Воспроизводимость
python generate_corpus.py — восстанавливает все CSV побитово (seed=42, без внешних зависимостей, Python 3.9+).

## Правовой статус
Данные синтетические, персональных данных не содержат (ФИО вымышлены и заменены
идентификаторами при использовании движком). Структура повторяет форматы открытых
данных ГИС «Торги» и ЕИС.
